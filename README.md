# AI SEO Workflow Automation Engine

## Overview
Stateful AI SEO automation engine using n8n, PostgreSQL, Ollama, and Qwen3.

## Current Pipeline
Keyword Intake
-> SERP Extraction
-> Keyword Clustering
-> AI Brief Generation
-> Structured Storage

## Tech Stack
- n8n
- PostgreSQL
- Ollama
- Qwen3
- Docker

## Current Features
- Keyword queue workflow
- SERP extraction and parsing
- Keyword clustering
- AI SEO brief generation
- Structured JSON outputs

## Planned Roadmap
- Full article generation
- SEO optimization
- Publishing
- Analytics/tracking
